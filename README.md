# What I Do

**Cloud & DevOps Engineering**
I design and build cloud infrastructure on AWS and Kubernetes, using Terraform and Docker to keep environments consistent and repeatable.

**DevSecOps**
I wire security scanning into CI/CD pipelines with Trivy, Kubesec, KubeLinter, and OPA Gatekeeper, so vulnerabilities get flagged before they ship, not after.

**Infrastructure Automation**
I automate deployments and monitoring end to end, cutting down manual ops work and making releases something teams don't have to worry about.
